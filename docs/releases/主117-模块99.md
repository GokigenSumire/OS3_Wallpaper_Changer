# 主117与模块99发布说明

## 新增与优化

- 已添加的多图组和文件夹来源增加图片／视频独立开关，默认均开启，动态照片归图片。关闭类型只影响下次换图资格，当前画面、来源记录、排序、单项停用和目录状态保留；桌面与锁屏独立保存。
- 参考、紧凑、打包及Cursor播放查询在去重前按来源过滤；重叠来源仍可各自提供允许的媒体。规则可以主动选择停用来源，但仍遵守分类和目录排除。
- 图库末级目录没有子目录时去掉展开箭头和无效点击／读屏动作，原层级对齐与启停操作保留。
- 主应用换为原创深蓝层叠画框图标，覆盖普通、适配、圆形、主题单色及应用内标识。模块99图标保持。

## 从上次公开版本以来的主要改进

- 原始文件／文件夹的创建和修改时间排序，未知创建时间不以复制或导入时间代替。
- 中文桌面／锁屏目标、悬浮切换与过渡，图库和播放统一多级目录及停用操作，当前媒体模糊填充与视频恢复连续性优化。
- 首次教学改为实际壁纸三手势操作；诊断顶部按P0～P11排列，P6／P7保持延期。
- 视频与动态照片的全局声音及逐项声音控制；只有正式可见播放、全局与单项均允许、有音轨且获得音频焦点时发声，预览静音。
- 每日定时和规则迁入当前应用界面，设置与诊断分组整理；关于卡片提供复制版本、手动更新及项目／发布下载链接。
- 模块99的兼容状态按已开启目标显示，关于区域提供独立版本更新入口，LSPosed描述精简为一句话。
