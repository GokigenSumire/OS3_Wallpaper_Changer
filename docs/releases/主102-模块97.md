# 主102／模块97正式发布

日期：2026-11-04；标签：`v1.3.4-p11-r102-m97`。主102采用已在小米17 Pro上获用户两批通过的原APK，不重编／重签；配套模块97沿用原包。

## 本次变化

- 支持本地视频与内嵌动态照片，保留高清原始封面；静音播放，可选循环／单次回照片／静态。
- 可分别开启锁屏后、解锁后从头播放，默认关闭，不推进历史。
- 修复视频导入的文件描述符生命周期与动态模糊采样条纹。
- 四栏整理：图库管理来源，播放集中队列／自动切换／媒体规则，特效保留适配／过渡与编辑，设置集中外观／兼容／高级和关于。
- 四主页面合并单行顶栏：左页名、中HOME／LOCK、右操作，正文说明精简，必要提示按需显示。
